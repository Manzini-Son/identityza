Frequently Addressed Inquiries

Can IdentityZA issue or correct an official ID document?

No. IdentityZA is an independent mathematical tool. To apply for a Smart ID card, correct personal records, or resolve duplicate ID queries, you must visit a local office of the Department of Home Affairs (DHA).

Can I use IdentityZA code in my commercial application?

Yes! Both the C++ core and JavaScript web engine are released under the MIT License, which permits free commercial and personal usage provided that the copyright and permission notice are preserved.

Reporting Security Concerns

If you identify a vulnerability in our web implementation or client-side calculation engine, please open a security advisory or email us directly. We treat cybersecurity and data protection with the utmost priority.
