Understanding South African ID Numbers

A South African National Identity number is a 13-digit numeric code formatted as YYMMDD SSSS C A Z. Each segment encodes specific biographical and verification data:

Segment Field Name Definition & Value Meaning
1–6 (YYMMDD) Date of Birth 2 digits each for Year, Month, and Day. Supports 1900s and 2000s centurial resolution.
7–10 (SSSS) Gender Sequence 0000–4999 indicates Female; 5000–9999 indicates Male.
11 (C) Citizenship 0 denotes a South African Citizen; 1 denotes a Permanent Resident.
12 (A) Index Digit Historical racial index, formerly used by DHA, now standardized as 8 or 9.
13 (Z) Check Digit Verification checksum calculated using the Luhn Algorithm.

How the Luhn Algorithm Validates South African IDs

The Luhn algorithm (also known as the "modulus 10" formula) detects accidental transcription errors and typos:

  1. Sum all digits in odd positions (1st, 3rd, 5th, 7th, 9th, 11th, and 13th).
  2. Concatenate all digits in even positions (2nd, 4th, 6th, 8th, 10th, and 12th) to form a single integer.
  3. Multiply this concatenated number by 2.
  4. Sum the individual digits of the resulting product.
  5. Add the two sums together. If the total is a multiple of 10 (total mod 10 = 0), the ID number is mathematically valid.

Frequently Asked Questions

Does a valid checksum mean the person is currently alive?

No. Checksum validation proves structural and algorithmic validity according to the official South African specification. To verify marital status, alive status, or Home Affairs records, a direct government DHA or certified credit bureau integration is required.

Is my ID number saved anywhere?

No. IdentityZA executes 100% inside your web browser using JavaScript. No ID numbers are transmitted to our servers or stored in any remote database.

Can this tool be integrated into signup forms?

Yes! You can use our lightweight client-side JavaScript engine or the standalone C++ CLI application for backend KYC and validation checks.
